Radix UI - Framer Motion - React Router - TanStack Query - React Hook

Token - RBAC - Socket.io - Multer + Cloudinary/MinIO - Zod validation -
Helmet, Rate Limit, CORS, Morgan

Architecture: - Clean Architecture - DDD - SOLID - Repository Pattern -
Service Layer - Feature-based folders
